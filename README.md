# Nomad AI — Офлайн Навигатор для iPhone

> Лёгкий автомобильный навигатор с офлайн-картами, поиском заправок/отелей и голосовым ИИ-ассистентом.  
> Устанавливается через **AltStore** без jailbreak.

---

## 📱 Возможности

| Функция | Онлайн | Офлайн |
|---|---|---|
| Навигация по маршруту | ✅ | ✅ |
| GPS и спидометр | ✅ | ✅ |
| Поиск заправок (150+ км) | ✅ | ✅* |
| Поиск отелей / магазинов | ✅ | ✅* |
| Несколько маршрутов | ✅ | ✅ |
| Промежуточные точки | ✅ | - |
| Пробки | ✅ | ❌ |
| Голосовой ассистент | ✅ | ✅ |
| Музыкальный плеер | ✅ | ✅ |

*\* Офлайн POI требует заранее скачанных карт регионов*

---

## 🚀 Установка на iPhone

1. Откройте [GitHub Actions](../../actions) → последняя сборка → скачайте `Nomad.ipa`
2. Откройте **AltStore** на iPhone
3. Перейдите в **My Apps** → нажмите **+**
4. Выберите скачанный `Nomad.ipa`
5. Готово! Приложение установлено 🎉

## 🗺️ Офлайн карты

### Как скачать карты для маршрута Новороссийск → Москва

В приложении перейдите в **Настройки → Офлайн карты** и выберите нужные регионы:

| Регион | Размер |
|---|---|
| Краснодарский край | ~120 МБ |
| Ростовская область | ~85 МБ |
| Воронежская область | ~70 МБ |
| Липецкая область | ~45 МБ |
| Тульская область | ~55 МБ |
| Московская область | ~200 МБ |
| **Весь маршрут (пакет)** | **~575 МБ** |

## 🎵 Музыка

1. Откройте стандартное приложение **Файлы** на iPhone
2. Перейдите в **На iPhone → Nomad → Music**
3. Скопируйте туда любые MP3/M4A файлы
4. В приложении скажите: *"Включи [название песни]"*

## 🛠️ Сборка из исходников

### Требования
- macOS 13+ с Xcode 15+
- [XcodeGen](https://github.com/yonaskolb/XcodeGen)

```bash
# Клонируем
git clone https://github.com/YOUR_USERNAME/nomad-ai.git
cd nomad-ai

# Генерируем проект
xcodegen generate

# Открываем в Xcode
open Nomad.xcodeproj
```

## 📄 Технологии

- **Swift / SwiftUI** — нативный UI
- **CoreLocation** — GPS с фоновым режимом
- **MapLibre GL Native** — офлайн карты
- **SFSpeechRecognizer** — офлайн распознавание голоса
- **AVSpeechSynthesizer** — синтез речи
- **OpenStreetMap / Overpass API** — POI данные
- **OSRM** — бесплатная онлайн маршрутизация
- **GitHub Actions** — автосборка .ipa
